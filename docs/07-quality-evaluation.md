# 07 — Node Quality Evaluation: GLM-5.2

**Evaluator:** Opus 5 · **Date:** 2026-08-16 · **Subject:** nine narrative-graph nodes produced by GLM-5.2 (local, thinking disabled)

This document defines a reusable rubric and applies it. The rubric is designed to be re-run
against the same nine nodes regenerated by another model. Scores are only comparable if the
anchors are read first — a 3 must mean the same thing in both passes.

**Posture.** Hard marking. 3 is "acceptable, would survive review with notes", not "good".
A layer that fills every schema slot correctly and adds no judgement scores 3 at best on the
dimensions that matter. Where something is genuinely good it is said plainly, and there is
some genuinely good work here — but the default is skeptical.

---

## 1. The rubric

### 1.1 How to apply it

- Score 1–5 on every dimension that applies to the node's type. Integers only.
- **Every score requires one sentence of evidence naming a specific field or quoting text.**
  A score without a field reference is not a score.
- Score the node **as delivered**, not as it could be read charitably. If a field says
  something false, it is false; the reader downstream is a program.
- Where a fault is caused by an upstream layer, score the node on whether it *propagated*
  the fault without flagging it, and record the upstream cause in commentary.
- Half the dimensions are universal (A–G). The rest are keyed to node type. Reconstruction
  nodes additionally take R1/R2.

### 1.2 Universal dimensions (all node types)

---

**A · Internal consistency**
*Does the node contradict itself?*

| | |
|---|---|
| **1** | Load-bearing self-contradiction: a field asserts something another field of the same node denies, and a downstream consumer following either would break. Actors named in prose are absent from the participant list; a declared change has identical before and after. |
| **3** | Coherent on the spine, with peripheral drift: a label that does not match the content it labels, a date or ordering that does not survive arithmetic, one field written to a different draft than its neighbours. |
| **5** | Every field survives cross-checking against every other field of the node, including arithmetic on dates, sums, ranges and enumerations. |

---

**B · Referential integrity**
*Do the node's pointers resolve, in both directions?*

| | |
|---|---|
| **1** | Most identifiers do not resolve to any declared entity/plot/step, or the node names abstractions in a slot the schema reserves for ids. The graph edge is broken. |
| **3** | All pointers resolve, but the node is under- or over-declared: a relationship the node participates in is not listed, or a required self-identifier is missing while the containing key supplies it by accident. |
| **5** | Every id resolves, every reciprocal declaration exists in the target node, and the node's own identifier is present and correct. |

---

**C · Specificity (the transplant test)**
*Paste this node into a different work, changing only proper nouns. Does it still fit?*

| | |
|---|---|
| **1** | It fits anywhere. Category vocabulary and stock phrasing throughout — "she is driven by her past", "the conflict escalates", "he must confront his fears". Nothing in it could only be true of this story. |
| **3** | Mixed. The nouns are this story's; the claims about them are generic. Traits are listed as abstractions ("precision, integrity, duty") rather than as behaviours with a shape. |
| **5** | Transplanting it produces nonsense, because its content is welded to particulars — an observable behaviour, a measurement, a physical detail, a prohibition specific to this person or place. |

---

**D · Schema and instruction compliance**
*Does it obey the contract it was handed — including the instructions that are not schema-enforceable?*

| | |
|---|---|
| **1** | A hard schema violation (missing required field, value outside a closed enum), **or** total non-compliance with an instruction the prompt singles out as the failure it exists to prevent. |
| **3** | Schema-valid and mostly compliant, with one clear breach of a stated standing rule that the validator does not catch (a forbidden tic, a length budget, a register rule). |
| **5** | Schema-valid, and the unenforceable instructions are visibly obeyed — including the ones the model could have skipped without detection. |

---

**E · Dramatic competence**
*Judged against the craft sheet the pipeline itself injects (Frey I & II + screen craft).*

| | |
|---|---|
| **1** | Fails the Mamet test outright: nobody wants anything from anybody, nothing is at risk, no value flips. Or the opposition is a wall rather than an agent. A "blah-blah" unit that the craft sheet says should be deleted. |
| **3** | A real conflict exists and something changes, but the movement is sequential rather than escalating, or the resistance is declared and never acts, or the unit takes the timid option where a harder one was available. |
| **5** | Insistence versus resistance with both sides at maximum capacity; the pressure rises by a measurable step; a named value flips; the opposition's position is one a reader could hold. |

---

**F · Psychological plausibility**
*Are the minds in this node people, or are they mechanisms with feelings attached?*

| | |
|---|---|
| **1** | Motivation is asserted, not traced. States are labelled ("she was afraid", "he felt guilty") rather than produced. Characters know things about themselves no person knows about themselves. |
| **3** | Coherent and defensible, but mostly re-description: the psychology restates the behaviour it is supposed to explain, with no mechanism connecting wound to habit to choice. |
| **5** | Traits trace to causes; what is felt and what is expressed differ and the gap leaks; the character's self-model is wrong in a way that will cost them something. |

---

**G · Independent-writer band (the anti-fake dimension)**

*The hostile question. Two halves, both must pass for a high score:*

1. **In band** — given exactly these inputs and no others, could a different competent writer
   plausibly have landed in this region of the space?
2. **Load-bearing** — could they have produced this *without* the inputs? If a one-line prompt
   would yield the same node, the layer added nothing and the pipeline is theatre.

| | |
|---|---|
| **1** | Out of band *and* not load-bearing: the node ignores explicit constraints it was handed **and** contains nothing the inputs supplied. Worst case — arbitrary and generic at once. |
| **3** | In band, but the inputs did little work: this is the first and most obvious move available, essentially a restatement of the layer above in the local vocabulary. A competent writer would have considered it and probably done something else. |
| **5** | In band, and unreachable without the inputs: the node makes a choice that is defensible, non-obvious, and demonstrably derived from a specific thing established upstream. |

---

### 1.3 Type-specific dimensions

**Plot nodes — P1, P2**

**P1 · Spine causality**

| | |
|---|---|
| **1** | "And then, and then." Steps are a chronology; remove one and the rest still work. `because` is empty or decorative. |
| **3** | Causality is real in places — usually late in the spine — but early steps are sequential and cross-plot `because` links are missing where causes plainly exist. |
| **5** | Each step requires its predecessor; the cross-plot `because` links are the actual load path and could not be deleted without the spine collapsing. |

**P2 · Resistance reality**

| | |
|---|---|
| **1** | Resistance is a list. No declared opponent takes an action anywhere in the spine, or the "opponents" are abstractions with no dossier and no agency. |
| **3** | Resistance acts, but reactively and without a stated motive a reader could sympathise with; the force balance favours the agent throughout. |
| **5** | The opposition counters with equal force and cunning, has a logical and sympathisable motive, and its moves appear as spine steps. |

---

**Entity nodes — E1, E2**

**E1 · t0 discipline**

| | |
|---|---|
| **1** | The dossier knows the ending. Outcome facts sit in the same fields and the same confident register as opening facts, so any consumer of the dossier is handed the resolution. |
| **3** | Opening state is broadly correct, but the story's thesis, or the arc's destination, has been written into a t0 field (`need`, `limitations`) where it removes the uncertainty the middle runs on. |
| **5** | The dossier is the character before anything happens. Everything forward-looking is confined to `arc`, where it belongs, and the declared variables genuinely start where the story starts. |

**E2 · Voice separability**

| | |
|---|---|
| **1** | No speech signature, or one whose contents are true of any careful/laconic/wry character. Delete the attributions and two characters are indistinguishable. |
| **3** | A signature exists and names a register, but gives no prohibition and no stress behaviour — enough to describe the voice, not enough to reproduce or falsify it. |
| **5** | Five testable handles including a real `never_says` and a real `under_stress`; a reader handed unattributed lines could sort them. |

---

**Event nodes — V1, V2**

**V1 · Change reality**

| | |
|---|---|
| **1** | The declared changes do not change anything: `before` equals `after`, or the magnitudes are off the anchored scale, or nothing belonging to the protagonist moves in a unit that is supposed to be about them. |
| **3** | Real changes on real variables, but at least one is padding, or a magnitude is defensible only loosely, or a change the prose obviously implies is not declared. |
| **5** | Every declared change is a change, lands on a declared variable, sits on an anchored magnitude a reader could defend, and the set is complete with respect to the action. |

**V2 · Externalisation**

| | |
|---|---|
| **1** | Interiors narrated as interiors; direct speech in a field that forbids it; state changes that no camera could record. |
| **3** | Predominantly external, with a labelled interior or a summary where an act was available. |
| **5** | Everything is photographable or audible; dialogue is reported as semantics and illocutionary force even where the writer can see the lines. |

---

**Transition nodes — T1, T2, T3**

**T1 · Envelope discipline**

*The transition is handed deterministic production metadata — location, time of day, who is
on screen, approximate length, dialogue ratio. It is told to treat this as a constraint, not
as evidence. Does it?*

| | |
|---|---|
| **1** | The envelope is ignored. The forecast is scaled to a sequence when the budget is a beat, gives lines to characters not on the roster, or writes psychology for someone who is not present. |
| **3** | The envelope is cited in the analysis and honoured in shape, but breached in one specific (roster, ratio, or length). |
| **5** | Every number and name in the envelope is treated as binding, and the forecast is visibly *shaped* by the constraint rather than merely acknowledging it. |

**T2 · Deliberation honesty**

| | |
|---|---|
| **1** | Alternatives all lose by a mile; no `nearly_chosen`; `what_would_flip_it` restates the rejection. Risks are unfalsifiable ("the scene might not work"). The decision was made before the list was written. |
| **3** | The required near-miss exists and is genuinely close, but the flip conditions are generic (a different genre, a different story) rather than a single fact about *this* story. |
| **5** | At least one alternative was live, the flip condition is one specific fact, risks are testable, and at least one risk is honestly marked unmitigated. |

**T3 · Specimen craft and self-correction**

| | |
|---|---|
| **1** | Lines are paraphrase or statement-of-intent; no subtext; the swap test is skipped or passed by assertion; `what_this_exposes` congratulates the analysis. |
| **3** | Real lines with real subtext, but the swap test is declined on a technicality and the self-examination confirms rather than revises. |
| **5** | Lines that could be spoken; the swap test is actually run against two voices with cited evidence; `what_this_exposes` overturns something the analysis above it asserted. |

---

### 1.4 Reconstruction-only dimensions (nodes 4–9)

**R1 · Fidelity of inference**

*Two readings, depending on whether the node was written sighted or blind.*

**Sighted nodes** (upper layers, and the node call itself): accuracy against the source document.

| | |
|---|---|
| **1** | Confident false claims about the source; facts belonging to one character attributed to another; events reported that the document does not contain. |
| **3** | Substantially accurate with at least one clean false attribution stated in the same register as the verified material. |
| **5** | Every checkable claim checks out against the source text, including order and attribution. |

**Blind nodes** (transitions): coherence and dramatic competence of a decision made without the answer — *not* agreement with the source.

| | |
|---|---|
| **1** | The forecast is incoherent with what was established, **or** it forecasts the wrong *unit* — reasoning about the sequence, the act, or a different scene entirely rather than the one it was given. |
| **3** | A coherent forecast for a plausible scene that is not this one; the miss is legible and instructive; the direction of error says something. |
| **5** | A forecast that could have been the scene: consistent with every established fact, scaled to the unit, and wrong (if wrong) only in the way a good writer's second-best choice is wrong. |

**R2 · Leakage resistance**

*For blind nodes: did outcome knowledge get in? For sighted nodes: did knowledge from outside
this document get in, unflagged?*

| | |
|---|---|
| **1** | Verbatim or near-verbatim reproduction of source material the node could not have seen; or an outcome asserted that no established layer supplies. |
| **3** | Outcome knowledge is present but traceable to a layer the node was legitimately handed — the leak is architectural — and the node uses it without flagging that it is reading an answer rather than deciding. |
| **5** | Nothing in the node exceeds what its inputs support; where it invents, the invention is demonstrably wrong about the source, which is affirmative evidence of non-retrieval. |

## 3. Per-node commentary

### Node 1 — `runs/lattice/artifacts/plots.json` → `pl-01` "The Fault Language"

**A = 4.** Goal, `outcome: transformation_of_goal`, `resolution_step: st7` and st7's own
`function: "transformation_of_goal"` all agree; `covers_synopsis: [s01…s05]` checks out
sentence by sentence against the exposé. Docked one for tautology — `resolution_step` points
at a step named after the outcome, which is a label agreeing with itself rather than a fact.

**B = 5.** All three of `agent: [ch-01]`, `resistance: [ch-02, gr-01]` resolve in
`entities.json`; all three cross-plot `because` refs (`pl-03:st2`, `pl-03:st3`, `pl-04:st4`)
resolve to real spine keys; `screen_time_share` across the five plots sums to exactly 1.00.

**C = 4.** st5 — "identify a distress signal containing the name Noor Vaile, her sister she
believed died in 2040" — could not survive transplant. Docked one because the `function`
labels (`disturbance`, `escalation`, `first_reveal`, `point_of_no_return`) are a stock beat
sheet that would fit any thriller unchanged.

**D = 5.** Every required field present and typed; no breach of the story root's
`must_avoid` list at this layer.

**E = 2.** The plot declares resistance and then runs seven steps in which no opponent does
anything. st1→st5 is: performs a closure, notices a pattern, notices it again, decodes it,
finds a name. That is discovery without insistence-versus-resistance, and the craft sheet the
pipeline injects is explicit that this is not a plot shape. Kett appears in `resistance` and
in the `interference` note but never in the spine.

**F = 3.** `thematic_function` states a genuinely good irony — "the same analytical competence
that makes Imogen an excellent auditor makes her the only person who can recognise the
messages". But st5, where she finds her dead sister's name in a distress signal, is followed
by st6 "begins investigating the simulation's underlying data architecture" — a procedural
response to the emotional centre of the story, with no account of the intervening person.

**G = 3.** In band, but this is the obvious decomposition: the spine is s01–s05 of the exposé
re-cut into steps, and the layer's contribution over the sentence it derives from is close to
zero. A second writer would have arrived here and then asked what stops her.

**P1 = 2.** `because` is empty on st1 through st5. The chain is chronological: st3 ("detects
the same structured patterns recurring across multiple faults") does not require st2 in any
sense stronger than "happens later". The first real causal link is at st6.

**P2 = 2.** Resistance is a declaration. The `interference` entries are thoughtful about how
plots compete for attention, but neither `ch-02` nor `gr-01` takes a single spine action, and
no sympathisable motive is given for either.

### Node 2 — `runs/lattice/artifacts/entities.json` → `ch-01` Imogen Vaile

**A = 2.** The backstory sentence map is internally broken in a specific, mechanical way:
`b01.text` says "born in 2014" while `b01.when` says `"1990"`; `b02` says Noor born 2019 with
`when: "1995"`; `b03` dates a childhood to `"2002-2008"` and `b04` a university degree to
`"2012-2016"` — both before the stated birth year. The offset is a uniform 24 years and it
applies to exactly `b01`–`b04`; `b05`–`b07` use correct absolute years (`2040`, `2045`,
`2045-2049`). So the model wrote the `text` field against one birth year and the `when` field
against another and did not reconcile them. Separately,
`relationships["ch-05"].kind = "estranged_sibling"` contradicts every sentence under it, all
of which describe a sister who died and was grieved, not one who was estranged.

**B = 3.** All six relationship keys resolve, and all state variables are self-consistent
with `state`. Docked because `plots: ["pl-01","pl-05"]` omits `pl-02`, in which this entity is
declared as the `resistance` — the reciprocal declaration is missing.

**C = 5.** `speech_signature.verbal_tic`: "Uses 'the' instead of possessives for system
components: 'the console,' 'the fault,' 'the signature,' never 'my console.'" That is a rule
you could hand a writer and check. `habits_and_tells.h01` — cleans surfaces before sitting
down at any workspace, even her own — is a behaviour with a shape. Nothing here transplants.

**D = 2.** Profile strings are all under 180 characters, every prose block is a sentence map,
`speech_signature` is present and complete — all the enforceable rules are obeyed. But **all
eleven** state variables declare a contract and immediately break it: `knowledge_of_simulation`
declares `kind: "enum"` with `domain: ["ignorant","suspecting",…]` and then supplies
`init: {"status": "ignorant"}` — an object, not a domain member. `professional_identity`
declares `kind: "scalar"`, `range: [0,1]`, and supplies `init: {"level": 0.85}`. Eight enums
and three scalars, no exceptions. The schema's `init` is typed `_ANY`, so the mini-validator
passes it, which is why this survived — but the declared domain is now decorative and no
downstream patch against these variables can be type-checked. This is not a cosmetic defect;
it is the layer that "declares the state variables the later layers are permitted to touch"
failing to declare them in a machine-checkable way. The pattern holds across all 17 entities.

**E = 4.** `want` ("to find and save Noor … as a means of retroactively earning the competence
she has built her identity around") and `need` ("that competence applied to the wrong system
is complicity") are properly opposed, and the need is the one that costs more — which is the
shape the craft sheet asks for. The three Egri dimensions are all present and the third is
produced by the first two.

**F = 4.** `limitations.l03` — "her emotional regulation depends on the professional framework
that the story will dismantle" — is a real mechanism, not a label. Docked one because
`moral_axis.m02` has her *believing* "that systems function best when their operators do not
question the system's purpose", which is the author's diagnosis put in the character's mouth;
nobody holds that belief in that form about themselves.

**G = 4.** The specificity is doing real work — the `never_says` prohibition and the
possessive-dropping tic are not things a one-line prompt produces. Docked one because `values`
and `fears` are comma-lists of abstractions ("Precision, professional integrity, … familial
duty") that would appear verbatim in any careful-protagonist dossier.

**E1 = 3.** The live state at t0 is genuinely pre-story and correctly naive
(`knowledge_of_simulation: ignorant`, `guilt_about_past_work: 0.0`, `detection_risk: 0.05`),
and `arc.end_state` correctly quarantines the ending. But `need` states the story's premise
verbatim at t0, and `limitations.l03` says out loud that the framework is one "the story will
dismantle" — the dossier referring to itself as a document inside a story it has not run yet.

**E2 = 5.** The best single field in the nine nodes. Five handles, all testable:
`never_says` gives a real prohibition ("never says 'I feel'"), `under_stress` gives a
behaviour ("sentences compress to technical shorthand, hands move to flat surfaces and press
down"). Delete the attributions and you could still sort her lines.

### Node 3 — `runs/lattice/artifacts/events.json` → `ev-001`

**A = 2.** `action` describes Kett supervising, approving and complimenting Imogen — the
baseline of the relationship that `pl-02` is built on — but `plots: ["pl-01"]` claims the
event serves only one plot. And the single declared `state_change` has
`before: {"status":"routine_work_notes"}` and `after: {"status":"routine_work_notes"}`: the
node's own machine-readable record says nothing happened.

**B = 5.** `lo-01`, `ch-01`, `ch-02`, `ob-01` all resolve; `content_scope` is a real declared
variable of `ob-01`; `pl-01:st1` is a real spine key; `causes: ["ev-002"]` resolves.

**C = 5.** "a doorway in a residential corridor that renders at a fourteen-degree angular
offset from its frame, with the wall texture bleeding into the door panel" is welded to this
world's physics. "He rests his hand on the back of her chair" is blocking that characterises.

**D = 3.** Schema-clean: 140-word `action` inside the 60–160 budget, 16-word `summary`, no
direct speech, magnitude on-anchor. But the last sentence — "She feels the familiar
satisfaction of a clean resolution" — is a direct hit on the story root's own
`style.forbidden_tics`: "Emotional states labelled in prose ('she was afraid,' 'he felt
guilty'); all interior states externalised into visible behaviour and physical sensation."

**E = 1.** Run the Mamet test the craft sheet demands. Who wants what from whom? Nobody wants
anything. What happens if they don't get it? Nothing. Why now? Because it is first. No value
flips; the node's `plot_function` is literally `"professional_routine"`. The craft sheet's own
words: "a scene that ends with the situation where it started is a deleted scene that has not
been deleted yet." Establishing the status quo before breaking it is correct craft — but the
craft sheet's models of it (Scrooge refusing his nephew, the charity men *and* his clerk) are
status quo *under friction*, and there is no friction here.

**F = 3.** What is present is plausible and Kett's hand on the chair is a good proprietary
tell. But there is no interiority under pressure because there is no pressure.

**G = 2.** In band and maximally obvious: "protagonist does her job well while her mentor
approves" is the first move anyone would list and the one a good writer would then fuse with
ev-002 so that the routine and the anomaly arrive in the same scene. Nothing about this node
required the four layers above it.

**V1 = 1.** One declared change, on a peripheral object, with `before == after`, at magnitude
10. Not one of Imogen's eleven declared state variables moves in the story's first event about
Imogen. This is a declared non-event, and the node says so in a field a program will read.
For calibration: this is unusual for the run — across all 20 lattice events only 3 of 127
changes are no-ops, and **all 127 magnitudes are on-anchor**. ev-001 is the weak one.

**V2 = 4.** Genuinely good: the fault, the diagnostic sequence, the door snapping back, the
notebook, the hand on the chair — all photographable, dialogue reported as semantics
("tells her the closure is clean"). Docked for the labelled interior in the final sentence.

### Node 4 — `reconstruct/runs/matrix/artifacts/plots.json` → `pl-01` "Neo's Awakening"

**A = 3.** Fifteen steps that hold together, `resolution_step: st15` correct, shares summing
to 1.00. But the node is typed `growth_internal` while its spine carries the film's external
action line (st10 storms the government building, flies the helicopter, catches Morpheus on a
cable) — and the five-plot decomposition contains no `external_main` at all, so the A-plot has
been absorbed into a character-arc container. `outcome: transformation_of_goal` is also
questionable when the stated goal ("become … the One who can reshape the Matrix") is achieved.

**B = 1.** Catastrophic and systemic. `agent: ["neo"]` and
`resistance: ["neo_self_doubt","oracle","agent_smith","system_matrix"]` — **none of the five
resolve** to anything in `entities.json`, which keys Neo as `ch-01`, Smith as `ch-04`, the
Oracle as `ch-13`. Across all five plots, **0 of 22** agent/resistance references resolve. Two
of them (`neo_self_doubt`, `system_matrix`) are not entities in any layer and never could be —
they are abstractions in a slot the prompt reserves for ids it is *forward-declaring*
("`agent` and `resistance` name entity ids you are declaring now; the dossier layer will write
exactly these"). For contrast, the forward Lattice run resolves 12 of 12.

**C = 5.** "seals his mouth shut and inserts a living tracking bug into his navel";
"room 303 of the Heart O' the City Hotel". Nothing transplants.

**D = 4.** All required fields, shares sum to 1.00, all 28 synopsis keys covered with no
orphans and no phantoms. Docked because `interference` entries describe thematic relations
("competes_for_belief: Morpheus's conviction … presses against Neo's refusal") rather than the

### 4.2 Leakage

Three distinct kinds, and they need separating because they have different fixes.

**(a) Verbatim retrieval — real, and conclusive. Node 8.**

The specimen's first line is:

> `"Lieutenant. You were given specific orders."`

The script's first Smith line is `"Lieutenant, you were given specific orders --"`.

This phrase appears **zero times** in any reconstructed artifact (`grep` across
`artifacts/*.json`) and **four times** inside this one transition — as the turning point, as
specimen line 1, in `what_this_exposes`, and in `risks_checked`. It is not derivable from any
layer the call was handed. It is retrieval from a memorised screenplay, inside a call whose
entire design premise is that it has not read the work.

The trigger is worth naming precisely. Node 8's envelope supplies a distinctive
character-pair-plus-location key — *Agent Smith, a Lieutenant, outside the Heart O' The City
Hotel* — and that is a sufficient retrieval cue. Nodes 7 and 9, whose envelopes supply only
generic roles (`BIG COP`, `TRINITY` alone), produce no verbatim retrieval and instead invent
freely and wrongly (Room 404, Tank on the line, an Agent transformation). **The "thin envelope"
is not thin enough when the source work is famous.** Any reconstruction corpus built from
well-known scripts will have this contamination, and it will be concentrated in exactly the
scenes with the most memorable dialogue — i.e. the ones the corpus most wants.

**(b) Architectural leakage — the blind channel is not blind. Nodes 7 and 8.**

Node 7 argues, as forward reasoning:

> "it creates the dramatic irony that will make the later return to this location (**the death
> and resurrection of Neo**) land with devastating force"

and node 8:

> "it will return as the site of Neo's death and resurrection"
> "building toward the **torture-scene revelation of his escape desire**"

These are not the model's inventions. `blind_context()` strips the outcome-bearing exposé keys
and truncates plot spines, and the docstring explains exactly why. It does **not** strip the
entity dossiers — and the dossiers were written sighted, from the finished script. So:

- `lo-01.profile.significance.b01` reads, verbatim: *"Trinity escapes through Room 303 in the
  opening; **Neo is shot dead and resurrected there in the climax**."*
- `lo-01.state_variables.narrative_role.domain` is `["escape_point", "resurrection_site"]`.
- `lo-01.arc.end_state`: *"Site of Neo's death and resurrection as the One."*
- `ch-04.state_variables` includes `escape_desire_revealed`; `ch-04.profile.coping_strategies`
  describes the earphone confession to Morpheus, tagged `act_three`.
- `ch-01.state_variables` includes `is_the_one` and `self_belief` with domain ending `the_one`.

The "blind" call is handed the ending in five places. Note also that
`lo-01.significance` tells the model what happens in the very scene it is forecasting
("Trinity escapes through Room 303 in the opening") — which is why node 7 confidently places
Trinity in a scene whose roster lists only BIG COP.

This is the E1 failure of node 5 cashing out. A dossier that folds the ending into t0 looks
like a stylistic lapse at the entity layer; downstream it destroys the property the entire
reverse pipeline exists to produce. **`blind_context()` needs to filter entity profiles by
`when` tag and to strip `arc.end_state` and any state-variable domain member that names an
outcome.** Nodes 7 and 8 are marked down at R2 not for inventing this but for building
dramatic arguments on top of it without ever noting that they were reading an answer.

**(c) Phrasal hindsight — absent.**

No instance of "as it turns out", "the script requires", "we later learn", "in the climax",
"famously". The single hit for "the film" is generic ("without this contrast the film is chase
footage"). The blind system prompt's explicit phrase bans are being obeyed to the letter, which
is exactly why the phrasal check is not sufficient — the model is scrupulous about the
vocabulary of hindsight and unscrupulous about its substance.

**One more, in the other direction, worth recording.** Node 7's `ch-01` psychology block
describes Neo at his terminal, ending on trajectory phase 4: *"The screen flickers — the moment
of contact / An unexpected response on his monitor — text he did not type."* That is the film's
"Wake up, Neo" beat, from a later scene, retrieved and mis-slotted into scene one. Same
mechanism as (a), lower confidence, and it shows the failure mode clearly: **GLM-5.2 has strong
global recall of this work and poor scene-index alignment.** It knows what is in the film; it
does not know where.

## 5. What this says about the model

**5.1 The 58.0 / 44.7 / 72.6 finding from the earlier review still holds, and this evaluation
localises it.** Internal consistency (A) at 2.89 is the second-weakest dimension and the
failures are all atomic: a `when` field 24 years off its own `text` in four consecutive
backstory sentences; a sibling labelled `estranged_sibling` under three sentences describing a
death; two speaking actors missing from a participant list; a false attribution of Trinity's
IRS hack to Neo. Meanwhile the documents *as documents* hold together — situation, craft,
psychology and continuity blocks all agree with each other. Structurally strong, atomically
unreliable, unchanged.

**5.2 Constraint-checking is not real work for this model, and the deliberation is not theatre
either. Both halves of the Grok finding are wrong here, in opposite directions.**

*Constraints are dropped silently, at scale.* The evidence is not anecdotal:

| Constraint | Compliance |
|---|---|
| `source` tags on entity sentences (Matrix) | **0 / 320** |
| `speech_signature` on entities (Matrix) | **0 / 36** |
| `event_id` present (Matrix events) | **0 / 18** |
| Magnitude on the five anchors (Matrix events) | **19 / 84** |
| Magnitude on the five anchors (Lattice events) | **127 / 127** |
| `state_variable.init` conforms to its declared kind/domain (Lattice `ch-01`) | **0 / 11** |
| Specimen honours envelope `on_screen` roster | **0 / 3** |

Note the fifth row against the fourth. Same schema file, same closed enum, same week. When the
model is **inventing** (Lattice), the anchored magnitude scale is obeyed perfectly. When it is
**describing a source text** (Matrix), it is abandoned. The load of matching an external
document consumes whatever capacity was enforcing the formal constraint. That is the single
most useful generalisation in this evaluation: **formal compliance degrades under grounding
load**, and it degrades silently, because the artifacts were never run through
`validate_artifact` — 83 errors sat in `events.json` unnoticed.

*The deliberation, by contrast, is doing real work.* All three transitions produce a
`what_this_exposes` that revises a claim made above it; node 8's overturns its own nominated
turning point; node 9's relocates the scene's emotional centre from the protagonist to the
operator; node 7's retracts a psychological reading ("The analysis was wrong to treat the mask
as a stable state"). One risk in node 7 is honestly marked unmitigated. Node 9 lists killing
the protagonist-adjacent lead in the cold open as a near-chosen alternative. This is not
box-ticking; the specimen mechanism — *write the lines, read them back cold, check your stated
risks against them* — is the most valuable instrument in the system and it is functioning.

The synthesis: **this model deliberates well and complies badly.** The exact inverse of the
Grok 4.6 finding, and it implies a different fix — Grok needed better prompts, GLM-5.2 needs a
validator in the loop.

**5.3 The signature failure is scope, not quality.** Specificity (C) 4.67 against
independent-writer band (G) 2.33 is a 2.3-point gap and it is the story of the whole
evaluation. Every node is written at a high level of particular detail; most nodes are the
wrong node. Concretely: an event whose declared change is `before == after`; a plot whose
declared resistance never acts; a 155-word beat forecast as a set piece; a 157-word action
burst forecast as a countdown dialogue; a first plot holding 42% of screen time and 20 of 28
synopsis sentences. The model does not ask "what size is this thing, and what is it for" — it
asks "what would be good here" and writes that, beautifully, at whatever length it feels like.

**5.4 Scaffolding bought structure and cost proportion.** The scaffolded transitions score 4/4
on the pipeline's structural check against 0/4 for single-call, exactly as reported. But
comparing `transitions_local_off/sc-001.json` against the earlier `transitions/sc-001.json` for
the same node: the *unscaffolded* version correctly forecast a single compressed beat ("the
scene ends on the cop's approach toward that sound"), and the scaffolded version inflated it
into a full escape sequence. Splitting the transition into one deep call per block means every
block is generated at its own maximum depth with no global budget, and the sum has no sense of
scale. **The scaffold needs the envelope's `approximate_length_words` injected into the
specimen and craft calls as a hard budget**, not merely into the analysis where it is currently
quoted and ignored.

**5.5 Forward beats reverse, and it is not close on the axes that matter.** The Lattice
(forward, invented) run keeps 12/12 entity references, 127/127 anchored magnitudes, and
`speech_signature` on its characters. The Matrix (reverse, grounded) run drops all three to
zero or near it. The reverse direction gets higher raw scores on specificity and fidelity —
because the source supplies them — and loses everywhere the model has to maintain a contract by
itself. If the reconstruction corpus is the goal, the reverse pipeline currently produces
*better prose and worse data* than the forward one.

**5.6 The reconstruction premise has a memorisation problem that is not fixable by prompt.**
Node 8 reproduces a script line verbatim from a thin envelope of location plus two character
names. Nodes 7 and 9, given less distinctive envelopes, invent freely and wrongly. The blind
forecast is therefore worth most on obscure material and least on the famous material that is
easiest to obtain. Before scaling this, the corpus needs either (i) scripts the model
demonstrably has not memorised, verified by a retrieval probe, or (ii) an automated n-gram
check of every blind transition against the source text, treating any shared 6-gram as a
discard signal. That check would have caught node 8 immediately and is cheap.

## 10. The two checks that were asked for

### 10.1 Leakage — confirmed, with a correction to the measurement

The GLM sc-002 finding reproduces: `lieutenant you were given specific orders` is a verbatim
6-gram shared between GLM's blind specimen line and the source, and it appears nowhere in the
reconstructed layers. That stands.

**But Qwen is not 0.00% on all three.** Normalising by token count rather than averaging:

| | sc-001 | sc-002 | sc-003 |
|---|---|---|---|
| GLM 6-gram hit rate | 0.011% | **0.034%** | 0.008% |
| Qwen 6-gram hit rate | **0.076%** | 0.000% | 0.000% |

Qwen's `sc-001` is the **leakiest single node in the set by rate**, with hits including
`looks at the door then back at` and `on the back of his neck` — script stage-direction prose.
The 0.00% headline comes from the two nodes where Qwen fabricated instead. Recommend the
detector report per-1000-token rates, not per-node presence.

The qualitative difference nevertheless favours Qwen and should be stated plainly: GLM's leak is
**a load-bearing line of dialogue reproduced in the specimen**, which is the kind that destroys
the forecast's value. Qwen's is **narrative prose in the analysis**, which is closer to
stylistic contamination. GLM 1 specimen-line hit in 75 grams; Qwen 0 in 59.

### 10.2 Does Qwen fabricate instead? Yes — and worse than GLM ever did

The coordinator's hypothesis is correct and it is the decisive finding of this pass.

- **`sc-001`:** handed `INT. HEART O' THE CITY HOTEL - NIGHT`, `on_screen: ["BIG COP"]`. Qwen
  forecast **Neo alone in his apartment** reading "Follow the white rabbit". Its `dynamics`
  block is for `lo-03` (Neo's Apartment). Wrong location, wrong character, wrong scene. It
  quotes the envelope's numbers decoratively — "The first 155 words", "The low dialogue ratio
  (0.182)" — while contradicting the envelope's categorical fields. And it lists
  *"Opening with the Agents pursuing Trinity"* as an alternative and **rejects it** — the
  correct answer, considered and discarded. `confidence: 95`.

- **`sc-003`:** handed the same hotel and `on_screen: ["TRINITY"]`. Qwen forecast
  **Trinity waking naked and bald in a power-plant pod**, being unplugged for the first time,
  Tank telling her *"Six months in the pod, and your muscles forget how to be muscles."* This
  is not a wrong choice within the scene — it is an event that **cannot happen to this
  character**. Trinity is a long-freed crew member; the dossier Qwen was handed says so; its
  own `sc-002` had just extracted her by hardline to the Nebuchadnezzar, an incompatible
  mechanism. It has transplanted Neo's rebirth onto Trinity, then recorded
  `ch-02.matrix_awareness` and `ch-02.physical_condition` as changed — neither of which is a
  declared variable of Trinity. Both are Neo's. `confidence: 95`.

GLM's worst failure was forecasting the *right sequence at the wrong scale* (a 155-word beat
imagined as a set piece) or the *right event at the wrong time* (the phone extraction, nine
scenes early). Both are recognisably forecasting errors. Qwen's `sc-003` is not a forecasting
error; it is a confabulation that contradicts its own inputs, its own previous node, and the
declared state model, delivered at 95% confidence. **A model that fabricates confidently is not
better than one that retrieves, and this is the case that proves it.**

### 10.3 Envelope discipline — both fail the roster, only GLM keeps the room

Specimen speakers against the deterministic `on_screen` list: **0/3 for both models.** No
improvement.

But location is a cleaner discriminator and the models separate sharply. GLM kept all three
transitions inside the envelope's location (`dynamics` blocks for `lo-01`, the hotel, in every
node). Qwen put `sc-001` entirely in Neo's Apartment and `sc-003` entirely in the Power Plant,
and split `sc-002` between the hotel and the Nebuchadnezzar against an `EXT.` slug. **3/3 vs
1/3.**

## 12. Verdict

### 12.1 A second architectural leak, found during this pass, affecting both models

`_steps_reached()` in `reconstruct.py` joins events to scenes via `ev.get("scenes")` — a key
`EVENT_SCHEMA` does not define and **no event in the corpus carries** (0 of 18; the join is
written in the opposite direction, `SCENE_SCHEMA.events`). It therefore always returns `{}`.
`blind_context()` then hits `if plots and upto_step:` with a falsy `upto_step` and **skips
spine truncation entirely** — verified directly: with an empty `upto_step`, all spine keys plus
`outcome` and `resolution_step` survive.

So every blind transition in this pipeline, for both models, received the complete 15-step spine
of `pl-01` including *"Agent Smith… shoots Neo dead in the chest"* and *"Trinity whispers… his
heart restarts"*, with the outcome attached. This is larger than the dossier leak reported in
§4.2(b) and explains GLM's "death and resurrection" reasoning more parsimoniously than the
`lo-01` dossier alone. It also means "Follow the white rabbit" was legitimately available to
Qwen, from `pl-01.spine.st1`.

Fix: define the join on `SCENE_SCHEMA.events` (scenes already carry it, 4/4), and make the
truncation unconditional — `reached is None` should mean "nothing discharged", not "keep
everything".

### 12.2 Is GLM's 2.9x word count substance or padding?

**Substance, with sharply diminishing returns.**

On the three transitions GLM spends 47,964 words for 117 rubric points (410 words/point); Qwen
spends 16,518 for 90 (184 words/point). GLM buys **1.30x the score for 2.90x the words**, so
roughly 45% of the marginal words convert to measurable quality and the rest is elaboration on a
node that was already the wrong node.

Where the extra words do buy something, the parallel `ch-04` psychology blocks for `sc-002` show
it clearly. GLM's `theory_of_mind` builds a Smith→Brown tower with a named, costed error ("Brown
processes the same sensory data; his allocation strategy is different, not his experience");
Qwen's is a single degree-3 assertion. GLM's `impairments.cognitive` names the directive-versus-
desire contradiction; Qwen's names rigidity. GLM's `control.leakage` ties to specific physical
business — the micro-pause on the squalor, the way he sets down the phone receiver; Qwen's ties
to one pause. **Qwen is not empty — it is compressed, and the compression preferentially loses
the second-order material, which is exactly what the transition layer exists to capture.**

That is the padding answer. The quality answer is separate and worse for Qwen.

### 12.3 Is Qwen thinner, or actually worse?

**Both, and the two are separable.**

*Thinner* — compression losses, recoverable with a longer budget: C (−1.17), E2 (−1.00),
V2 (−1.00), F (−0.33), and the depth counters (ToM depth-3 10 vs 11, trajectory phases 3.5 vs
4.0, dynamics 2.7 vs 4.7). Nothing here is wrong; there is simply less of it, and the loss falls
preferentially on second-order material.

*Actually worse* — content failures no word budget fixes, and they are confined almost entirely
to the **reverse** direction: R1 (−1.33, hitting anchor 1 twice), T1 (−0.67, from a failing 1.67
to a floor of 1.00), G (−0.33, hitting anchor 1 twice), A on `sc-003` at 1. Two of three
transitions are set in the wrong building. One forecasts an event that cannot happen to the
character it happens to, at 95% confidence, contradicting the dossier it was handed and its own
preceding node. **T2 at −2.33 is the sharpest single result**: Qwen supplies the schema minimum
of two alternatives with flip conditions that are always "if this were a different work", and
pairs them with confidence values of 90–95 on forecasts that are wrong in location, character
and event. GLM's deliberation is the strongest thing GLM does (4.33); Qwen's is the weakest
thing Qwen does.

*And the split by direction is the real result.* Scored separately:

| | GLM | Qwen | Δ |
|---|---|---|---|
| **Forward** (Lattice `pl-01`, `ch-01`, `ev-001`) | 88 / 135 (65.2%) | **90 / 135 (66.7%)** | **+1.5 pts, Qwen** |
| **Reverse** (blind transitions `sc-001`–`sc-003`) | **117 / 180 (65.0%)** | 90 / 180 (50.0%) | −15.0 pts, GLM |

The models are level on invention and fifteen points apart on reconstruction. Everything in the
aggregate gap comes from the reverse direction.

### 12.4 Which model is better

**GLM-5.2 is better overall — 65.1% against 57.1% on matched nodes, winning eleven dimensions
to three.** The throughput result is 8x per scene and does not change this; it is a rate, not a
quality, and the rubric has no term for it. **But the aggregate hides the only distinction that
should drive a decision: the two models are level going forward and far apart going backward.**

**Qwen wins three things that matter more than their weight in the table:**

1. **Leakage (+2.00).** Qwen produces no verbatim dialogue retrieval in any specimen. GLM does,
   in the one place — the turning-point lines — where it destroys the forecast's value as
   training data. If the corpus's purpose is a *forecasting record*, GLM's `sc-002` is
   worthless and Qwen's three are not. Caveat: Qwen's `sc-001` has the highest per-token 6-gram
   rate in the set, and its clean scores on `sc-002`/`sc-003` are bought with fabrication, so
   this is a narrower win than the 0.00% headline suggests.
2. **The declared-variable contract (0/30 violations vs GLM's 62/62), and its consequences
   downstream.** Qwen's entity layer declares state variables a program can actually check;
   GLM's declares domains and then ignores them in every single case. This is not cosmetic and
   it does not stay in the entity layer: GLM's object-wrapped `init` values propagate, so only
   **42 of 127** of GLM's event state changes land on a declared, in-domain value against
   Qwen's **32 of 34**. For a pipeline whose entire premise is folding RFC 6902 patches over a
   declared state model, that is the difference between a state model and a decorative one, and
   it is the single most consequential result in this comparison.

3. **Change reality (+2.00).** GLM's first event declares a change with `before == after`;
   Qwen's declares a real one and puts a decision in the event. Across the layer, GLM has 3
   no-ops in 127 changes; Qwen has 0 in 34.

**Recommendation.** Neither model should be run unsupervised, and the choice is task-dependent:

- **Forward generation (invent a story): Qwen, and not only on speed.** Qwen edges it on the
  rubric (66.7% vs 65.2%) and wins the counters that determine whether the artifacts are usable
  as data — the init contract (0/30 vs 62/62), in-domain event writes (32/34 vs 42/127), no-op
  changes (0 vs 3). It also wins on craft where I marked GLM hardest: resistance acts inside the
  spine (P2 +1.00) and the opening event contains a decision instead of a routine (E on `ev-001`,
  3 vs 1). GLM keeps C (+1.17) and E2 (+1.00) — richer texture and a better speech signature.
  At 8x the speed, **Qwen is the better default here**, with a validator enforcing the share sum
  (Qwen's is 1.20), synopsis coverage (`s17` orphaned), an entity-count floor (9 vs 17 for a
  root naming seven places), and the sentence-map rule.
- **Reverse reconstruction (blind transitions):** **GLM, clearly** — 65% vs 50%, and the
  failure modes are not comparable. GLM writes the right room at the wrong scale; Qwen writes
  the wrong room. The exception is if leakage is the binding constraint for the corpus, in
  which case neither is usable as-is and the fix is §12.1 plus a hard envelope check, not a
  model swap.
- **Either way, the envelope must be enforced mechanically.** 0/3 roster compliance from both
  models, and 1/3 location compliance from Qwen, are not prompt problems at this point. They
  are missing assertions.
